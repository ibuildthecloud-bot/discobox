Print what a discobox's terminal shows, as a person looking at it would read it:
the rendered screen, not the escape sequences that drew it. Reading does not
attach, resize the terminal, or count as activity.

Every row of the screen is printed, blank ones included, so a row can be found
by its place on the screen; --trim drops the blank rows below the last line
written. A discobox that is not running is read from the screen it last
posted, and says so on stderr.

Examples:
  discobox capture mybox
  discobox capture mybox --scrollback 200 --trim

Usage:
  discobox capture DISCOBOX [flags]

Options:
  -h, --help               help for capture
      --scrollback N       also print up to N lines above the screen
  -t, --terminal TERMINAL  use TERMINAL (default primary)
      --trim               drop the blank rows below the last line written

Global options:
      --color WHEN         set color WHEN to auto, always, or never (default auto)
      --debug              print HTTP requests and the git commands run on this machine
  -o, --output FORMAT      output FORMAT: table or json (default table)
      --server SERVER      connect to SERVER, an endpoint or a registered server's name; defaults to the primary "discobox admin remote primary" set, and to the local server when none is
      --token TOKEN        bearer TOKEN for API requests
